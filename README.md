This is a specialized calculator for the table-top role-playing game Burning Wheel https://www.burningwheel.com/collections/burning-wheel

In this game players gather a pool of 6-sided dice and roll them to determine who has the most successes. The pools differ, so does the minimum value per die considered a success, and there's the possibility of exploding 6s for extra successes. This makes estimating your odds of success at any particular roll non-trivial. This page is meant to alleviate that. Vibe-coded.

Available at https://rauljcosta.github.io/BurningWheelVersus/
